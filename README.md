# Retrieval-and-Structuring Augmented Generation for Data Mining

This repository contains the CMPE 255 short-story assignment based on:

> Jiang, P., Ouyang, S., Jiao, Y., Zhong, M., Tian, R., and Han, J. “A Survey on Retrieval And Structuring Augmented Generation with Large Language Models.” Proceedings of ACM SIGKDD 2025. arXiv:2509.10697.

## Project idea

The project studies how data-mining systems can improve ordinary retrieval-augmented generation by adding structure to retrieved information. The survey connects information retrieval, text mining, taxonomy construction, information extraction, knowledge graphs, and large-language-model reasoning.

## Main argument

Ordinary RAG retrieves passages. Retrieval-and-Structuring Augmented Generation (RAS) adds an intermediate data-mining layer that organizes evidence into useful structures before the language model reasons over it. This can improve traceability and domain-specific reasoning, but it also introduces new failure points: poor retrieval, incorrect structure, stale knowledge, and integration cost.
